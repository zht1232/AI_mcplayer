# 拾野 v0.1.2

本次为客户端开发预发布，目标 Minecraft 26.2、Fabric 0.19.5、Java 25。

- 改名拾野（Wildling），更新面板配色和用语，状态/错误不再刷屏。
- 按任务选择观察数据，压缩逐字符样式，增加按需 `observe`、`inspect_slot`。
- 修复普通回复或 `chat_say` 未结束对话，导致重复问候与公共任务排队的问题。
- 向模型提供附近实际可达位置，修复跟随更新与行走进度共用计时器。
- 后台模型启动支持窗口关闭后继续运行；保留 4B、32768 上下文与 256 token 思考预算。

验证：单元测试、真实隔离客户端/服务器 UI 与行动测试；一份现场导出的观察部分从 11244 token 降到聊天 648、工作 2352（不包含工具定义和提示词）。本地规划测试分别返回了正常聊天动作和 `move_to`。

部署：下载 jar 或部署 zip，移出旧版本 jar，安装到实际实例的 `mods`；版本隔离用户需使用版本目录。保留 `mc-ai-partner.json`，重启客户端。具体步骤见部署说明。

限制：复杂地形、正式服完整插件组合和长期自主生存未完成验收；资源包图片语义没有接入视觉模型。这些测试不构成完整能力保证。
