# 拾野 v0.1.6

延续 v0.1.5 的菜单、聊天、分层知识和生存修复，重点让技能连续执行。

- 基础自主采集优先执行，不再先等待模型的口头计划；模型等待期间也可取消过期规划并继续已有安全工作。
- 采集尝试真正可站立、能看到目标的操作位置；限制寻路次数、对失败目标退避，并等待较晚到达的掉落数据。
- 木板/木棍/工作台 → 放置或复用工作台 → 木斧/木镐/木剑，按原版背包点击持续执行并验证服务端物品。
- 新增连续觅食：优先已有掉落食物、成熟浆果，再猎取可见成年食用动物；战斗和低血量抢占。
- 防御可以尝试其他安全撤退方向，低血量时使用已有补给；避免战斗永远挡住进食状态。
- 可见长测试独立控制窗口与后台限速；实际核对种子、生存模式、普通难度及完整背包/世界时间，并区分基本进展和完整生存指标。

34 项单元测试和可见客户端/隔离服务器任务回归通过。自然世界长测试的最终证据见自然世界测试记录；本次仍是开发预发布，不宣称完整正式服插件组合或全科技树已经验收。
