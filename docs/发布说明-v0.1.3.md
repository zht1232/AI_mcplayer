# 拾野 v0.1.3

Minecraft 26.2 / Fabric 0.19.5 / Java 25 客户端开发预发布。包含 0.1.2 的拾野命名、面板、按任务观察、聊天任务结束与导航修复。

- 本地模型和新配置默认关闭推理，保留原 4B、32768 上下文、1024 响应预算。
- F8 → 连接增加“推理：关/开”和协议选择；保存后重新开始接管。
- 每次请求按 llama.cpp、模板/vLLM、通义或 DeepSeek 的协议发送开关。自动模式识别本机、DeepSeek、通义；其他地址需要手动选择协议，none 不发送扩展字段。
- 请求层测试捕获各协议开关的实际 JSON；真实 Fabric 客户端测试验证界面切换与配置持久化。

默认关闭推理降低思考生成耗时；实际完整请求延迟仍取决于输入、输出和硬件。开关需模型与后端支持。

下载 jar 或部署 zip，安装到实际实例 mods，保留 mc-ai-partner.json，移出旧版本并重启客户端。完整正式服插件组合与长期自主生存尚未验收；资源包图片语义尚未接入视觉模型。
