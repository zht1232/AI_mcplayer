# 任务级验收

这些场景由真实 Fabric 客户端连接隔离测试服务器执行，检查服务器状态和背包/血量，不以聊天宣称完成作为证据。

| 任务/场景 | 验收结果要求 | 自动化入口 |
|---|---|---|
| 连续采木恢复 | 模型连续只有计划时，实际接近原木、挖掘、拾取，背包增加；计划不刷公共聊天 | PartnerUiGameTest.testNoActionRecovery |
| 基础合成链 | 3 原木为材料，原版 2x2 点击得到木板再合成工作台，检查服务端背包，聊天栏保持打开 | SurvivalGameTest |
| 连续工作台合成 | 正常放置/复用工作台，合成木斧/木镐/木剑，服务端精确核对材料和工具；取消后材料不丢失，恢复聊天/暂停覆盖层 | WorkbenchSkillGameTest |
| 连续觅食 | 掉落面包优先、成熟浆果正常右键、成年猪正常近战与拾取；服务端检查食物数量，保持聊天/暂停覆盖层 | ForageSkillGameTest |
| 大麦田连续收割 | 56 株成熟与 8 株未成熟的小麦，本地请求 16 个，再收到公共请求 8 个；背包新增至少 24 个、服务器至少 24 株被收割、未成熟株保持、两个数量任务按优先级完成 | SurvivalGameTest |
| 展示实体识别 | 展示小麦读取真实 item ID/名称及对应逻辑作物，不能只给模型一个 item_display 类型 | SurvivalGameTest |
| 聊天栏中干活 | 保留聊天草稿，持续行走、收割、食物自救；不打开背包或关闭聊天栏 | SurvivalGameTest |
| 聊天栏中防御 | 挖掘被敌对生物打断，选武器并真实扣僵尸血，保留聊天栏；结束恢复选择，苦力怕尝试后撤 | CombatReflexGameTest |
| 缺血缺食物自救 | 食物在主背包，正常交换到快捷栏并食用；服务器饥饿和血量真实恢复 | SurvivalGameTest |
| 被围住脱困 | 两格高土墙包围，不调用模型，正常挖开安全出口并走出去，服务器确认位置 | SurvivalGameTest |
| Esc 中继续工作 | 保留 Esc 菜单，正常走到目标并挖掘，服务器确认结果 | PartnerUiGameTest |
| 插件式界面链 | 箱子左右/Shift 操作、聊天命令按钮、Dialog 操作、BossBar 数据、过期请求取消与恢复 | PartnerUiGameTest |
| 直接 API 密钥 | 面板直接保存/清除密钥，显示遮罩；实际 HTTP 认证头正确，观察/错误不泄露密钥 | AiBrainTest、PartnerUiGameTest |
| 经验记忆 | 重复错误形成有界经验文件，重启后仍检索；按服务器隔离，禁止目录越界、覆盖基础技能或保存凭据 | RuntimeSkillBookTest |

正式服务器还需复测：CraftEngine 实际作物的逻辑方块、不同成长阶段与交互方式；DeluxeMenus/QuickShop/TrChat/AuthMe/领地/反作弊组合；长期资源补给、合成和种植闭环。隔离测试里用展示实体关联真实小麦模拟感知，不宣称已经覆盖全部 CraftEngine 配置。

自然世界 30 分钟验收使用独立自然生成服务器、正常难度和真实本地 Qwen3.5-4B；不赠送物资/血量、不加速时间。测试用隐藏图形上下文，不显示桌面窗口，限制渲染 30 FPS 并保留正常 tick。每 30 秒记录位置、血量、饥饿、物资、模型错误和世界时间。第一轮后台限速导致模拟世界滞后，单列为基线，不将“进程存活”冒充完整昼夜生存成功。
