# 拾野 v0.1.2 部署

这是 **Minecraft 26.2 / Fabric / Java 25 客户端 mod**。服务器不需要安装本项目插件。

1. 关闭将要安装模组的客户端。
2. 从 Release 下载 `wildling-0.1.2.jar`，放进该实例的 `mods` 文件夹，并安装 Fabric API `0.161.0+26.2`。部署 zip 的 `mods` 文件夹包含这两个 jar。
3. 将旧 `mc-ai-partner-*.jar` 移出 `mods`；新旧文件使用同一内部 mod ID，不能同时加载。
4. 版本隔离启动器应使用当前版本目录下的 `mods`。本项目桌面实例的实际路径是 `客户端/.minecraft/versions/MC-AI-Partner-Fabric-26.2/mods`。
5. 正常进服和登录后，按 F8 打开拾野，配置模型连接，再“开始接管”。当前登录账号会由模组控制。

也可以运行部署包里的 `scripts/install-mod.ps1 -InstanceDir '实际实例目录'`，脚本只备份并替换拾野旧 jar，保留配置；客户端占用文件时会提示先关闭，不会结束游戏进程。

## 升级兼容

内部 mod ID `mc_ai_partner`、`config/mc-ai-partner.json` 和旧 `/aip` 命令保留；增加 `/wildling` 命令别名。保留自己的配置。若原规划间隔为 8 秒，可在连接关闭后改为 `decisionIntervalSeconds: 2` 并重载配置。

## 模型

需要支持原生 function calling 的 OpenAI 兼容后端。可用本地 Qwen3.5-4B，也可配置 API。API key 通过环境变量提供，配置中只保存变量名。默认后端 `http://127.0.0.1:8080/v1`，别名 `Qwen3.5-4B`。

本地启动脚本保留 32768 上下文、开启思考并限制预算为 256 token。仓库与部署包不包含 GGUF、llama.cpp、Minecraft 本体、启动器账号或任何密钥。

## 验证与限制

编译、单元测试、隔离真实客户端/服务器的 UI、聊天、取消恢复、可达位置、移动和挖掘测试通过。现场观察分词对比证明了输入压缩效果。完整正式服插件组合与长期自主生存尚未验收；资源包图像语义目前没有视觉模型。
