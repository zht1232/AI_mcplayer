# 拾野 v0.1.5

Minecraft 26.2 / Fabric / Java 25 客户端开发预发布，包含 v0.1.4 的采集和防御修复。

- API 密钥可直接在连接页填写并遮罩显示，旧环境变量配置兼容；推理参数显示为兼容选项，默认自动。
- 修复自身聊天回声和错误长期笔记强化同一判断的问题；只检查背包不再打开物品栏。
- 资源数量任务持续执行，成熟作物和展示实体数据增加物品、逻辑方块、距离等信息；资源观察先按距离排序，避免大田只看到远角。
- 聊天栏和 Esc 打开时仍继续移动、挖掘和防御，输入草稿与本地密钥不会进入观察。
- 自动使用已有安全食物和治疗/再生药水，缺补给或受困时简短求助；可挖开安全、可破坏的受困出口。
- 新增 config/wildling/skills/SKILL.md 及生存/战斗/菜单/服务器知识目录；按需读取，经验持久化，拒绝明显未经验证的“展示实体都是假作物”推断。
- 扩充任务级验收与参考项目对照。模型默认仍关闭推理，保留原本地 4B 和 32K 上下文。

下载 jar 或部署包，安装到实际版本隔离实例的 mods，保留配置并重启客户端。正式服的全部自定义作物、复杂战斗与长期生存仍需复测；当前技能学习是知识积累和既有动作组合，不会自动训练模型权重或改写模组程序。
